El sistema debe permitir al usuario Maestro eliminar sucursales existentes.

El sistema debe mantener la integridad de los datos al eliminar sucursales, asegurando que no queden registros huérfanos o inconsistentes.

A la hora de que el usuario maestro elimine una sucursal, debe de eliminar el cascada todos los demas datos de esa sucursal, es decir cualquier suscriptor, entrenador, o dato que este relacionado a la sucursal de debe borrar, excepto claro los datos que sean multisucursales, esos no se tocan

el boton eliminar sucursal se debe utilizar para limpiar todo dato que tenga que ver con esa sucursal de la bd, entonces debe pedir confirmacion
